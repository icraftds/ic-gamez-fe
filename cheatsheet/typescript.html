Primitive & Basic Types

Pondasi sistem pengetikan statis TypeScript untuk mendeteksi bug sebelum kode dijalankan di runtime.

unknown vs any vs never Safety

Perbedaan mendasar tingkat keamanan tipe data penampung di TypeScript.

let valAny: any = "halo"; valAny.toUpperCase(); // Bebas tapi tidak aman! let valUnknown: unknown = "halo"; // Aman, wajib pengecekan tipe sebelum diakses if (typeof valUnknown === "string") valUnknown.toUpperCase(); function throwError(msg: string): never { throw new Error(msg); } // Tidak pernah return
any: Mematikan type checker sama sekali (hindari sebisa mungkin di codebase produksi).
unknown: Type-safe counterpart dari any. Wajib diverifikasi dengan narrowing sebelum dipanggil metodenya.
never: Merepresentasikan nilai yang mustahil ada (fungsi throw error tiada henti, infinite loop, atau exhaustive switch case).
Union (|) & Tuple [T, U] Structures

Menggabungkan opsi tipe atau mendefinisikan array dengan panjang dan tipe urutan tetap.

// Union: Nilai bisa salah satu dari tipe type Status = "pending" | "success" | "error"; type ID = string | number; // Tuple: Array dengan jumlah dan posisi tipe pasti type LatLng = [number, number]; const coordinates: LatLng = [-6.2088, 106.8456]; // Valid Jakarta coords
Tips: Gunakan `readonly [number, number]` jika ingin mencegah mutasi array tuple menggunakan metode `.push()`.

Interface vs Type Alias

Pertanyaan wawancara paling populer: kapan harus menggunakan interface dan kapan type.

Declaration Merging & Extends Comparison

Aturan praktis: gunakan `interface` untuk blueprint objek/OOP yang dapat diekstensi, dan `type` untuk union, primitives, tuple, atau transformasi.

// 1. Interface mendukung Declaration Merging (cocok untuk pustaka / plugin) interface User { id: string; name: string; } interface User { role: "admin" | "member"; } // Otomatis digabung! // 2. Extends pada Interface vs Intersection (&) pada Type interface AdminUser extends User { permissions: string[]; } type Employee = { id: number; name: string; } & { salary: number; };
Interface: Hanya untuk mendeskripsikan bentuk Object atau Class. Mendukung declaration merging.
Type: Jauh lebih fleksibel; bisa merepresentasikan union (`A | B`), tuple, fungsi sederhana, dan primitive aliases.

Generics & Type Constraints

Menciptakan komponen reusable yang bekerja dengan berbagai tipe data tanpa kehilangan type safety.

Generic Function with <T extends Constraint> Reusability

Membatasi parameter tipe generik agar harus memiliki properti tertentu menggunakan klausa `extends`.

interface HasId { id: string | number; } function findById(items: T[], targetId: string | number): T | undefined { return items.find(item => item.id === targetId); } // Wrapper ApiResponse Generik interface ApiResponse { data: TData; statusCode: number; success: boolean; }
Tips: Jangan buat fungsi generik jika tipe `T` hanya digunakan di satu tempat saja dalam argumen fungsi tanpa di-return.

Utility Types Esensial

Utility bawaan TypeScript untuk mentransformasi tipe data yang ada menjadi bentuk baru dengan efisien.

Partial, Required & Readonly Modifiers

Mengubah seluruh properti objek menjadi opsional, wajib, atau read-only.

interface Product { id: number; name: string; price?: number; } type UpdateProductInput = Partial; // Semua properti jadi opsional (?) type FullProduct = Required; // Semua properti wajib ada type ImmutableProduct = Readonly; // Properti tidak bisa di-reassign (x.price = 100 Error!)
Pick<T, K>, Omit<T, K> & Record<K, T> Selection

Memilih subset properti, membuang properti yang tidak diinginkan, atau mendefinisikan dictionary map.

interface User { id: number; name: string; email: string; passwordHash: string; } // Ambil hanya name dan email untuk respons public type PublicProfile = Pick; // Buang passwordHash dari User type SafeUser = Omit; // Key-Value Dictionary dengan key string tertentu type RolePermissions = Record<"admin" | "editor" | "viewer", string[]>;
ReturnType<T> & Exclude<T, U> Inference

Mengekstrak tipe kembalian fungsi atau memfilter anggota union type.

type EventType = "click" | "hover" | "scroll" | "keydown"; type MouseEvents = Exclude; // "click" | "hover" function createSession() { return { token: "abc-123", expiresAt: new Date(), userId: 42 }; } type Session = ReturnType; // { token: string; expiresAt: Date; userId: number; }

Type Narrowing & Custom Type Guards

Cara aman menyempitkan tipe union ke tipe spesifik di dalam blok logika kode.

Discriminated Unions & 'value is Type' Pattern

Pola standar industri untuk menangani berbagai bentuk state dan mendefinisikan type predicate kustom.

// Discriminated Union (memiliki properti pembeda literal yang sama: status) type ApiState = | { status: "loading" } | { status: "success"; data: string[] } | { status: "error"; error: Error }; function render(state: ApiState) { if (state.status === "success") { console.log(state.data.length); // TS tahu state memiliki field data! } } // Custom Type Guard menggunakan predikat `is` function isString(val: unknown): val is string { return typeof val === "string"; }

keyof, typeof & as const

Operator level lanjut untuk menghasilkan tipe otomatis dari struktur data JavaScript.

as const & keyof typeof Optimization

Membuat nilai read-only literal object dan mengonversinya menjadi tipe union otomatis tanpa redundant Enum.

const HTTP_STATUS = { OK: 200, NOT_FOUND: 404, SERVER_ERROR: 500, } as const; // Semua properti berstatus readonly literal type HttpStatus = typeof HTTP_STATUS[keyof typeof HTTP_STATUS]; // 200 | 404 | 500 type StatusKey = keyof typeof HTTP_STATUS; // "OK" | "NOT_FOUND" | "SERVER_ERROR"
Tips Wawancara: Pola `as const` objek jauh lebih disukai daripada `enum` TypeScript tradisional karena menghasilkan ukuran bundle JS yang jauh lebih ramping dan tree-shakeable.

tsconfig.json Best Practices

Konfigurasi compiler standar industri untuk proyek enterprise yang aman dan modern.

Enterprise tsconfig.json Setup Configuration

Opsi compiler esensial yang wajib diaktifkan pada proyek produksi.

{ "compilerOptions": { "target": "ES2022", "module": "NodeNext", "moduleResolution": "NodeNext", "strict": true, /* Aktifkan semua pemeriksaan tipe ketat */ "noImplicitAny": true, /* Tolak variabel tanpa tipe eksplisit */ "strictNullChecks": true, /* Jangan izinkan null/undefined sembarangan */ "noUncheckedIndexedAccess": true, /* Objek array indexing mengembalikan T | undefined */ "skipLibCheck": true, /* Percepat waktu compile dengan lewati type checking di node_modules */ "forceConsistentCasingInFileNames": true } }
