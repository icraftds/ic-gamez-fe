Docker & Containerization Cheatsheet

Panduan praktis teknologi kontainer Docker. Menguasai manajemen lifecycle container (run, exec, logs), perakitan gambar efisien via Dockerfile multi-stage, orkestrasi multi-service docker-compose.yml, serta manajemen persistent volume data.

Kategori 01

Perintah Inti Container CLI

docker run & flags

Menjalankan container dari image. Flag -d detached di latar belakang, -p port mapping (Host:Container), --name beri nama kontainer.

docker run -d -p 3000:3000 --name my-app node:18-alpine
docker ps, logs & exec
docker ps                   # Lihat container yang sedang berjalan
docker ps -a                # Lihat semua container (termasuk yang mati)
docker logs -f my-app       # Pantau log output container secara realtime
docker exec -it my-app bash  # Masuk ke dalam terminal shell container
Kategori 02

Sintaks & Struktur Dockerfile

Resep pembuatan container image produksi (Multi-stage build):

# 1. Base Image
FROM node:20-alpine AS builder
WORKDIR /app

# 2. Dependencies Caching
COPY package*.json ./
RUN npm ci

# 3. Copy Source Code & Build
COPY . .
RUN npm run build

# 4. Production Runner Stage
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
CMD vs ENTRYPOINT: ENTRYPOINT menentukan perintah utama yang pasti dijalankan, sedangkan CMD menyediakan argumen default yang dapat ditimpa saat docker run.
Kategori 03

Docker Compose (Multi-Service YAML)

Contoh berkas docker-compose.yml untuk aplikasi Web dan Database PostgreSQL:

services:
  web:
    build: .
    ports:
      - "3000:3000"
    environment:
      - DB_HOST=db
    depends_on:
      - db

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: rahasia123
    volumes:
      - pgdata:/var/lib/postgresql/data

volumes:
  pgdata:
Perintah ComposeFungsi
docker compose up -dMenjalankan semua service di latar belakang.
docker compose downMenghentikan dan menghapus container service beserta jaringannya.
docker compose restart webMe-restart satu service tertentu.
Kategori 04

Volumes: Persistensi Data

Named Volume vs Bind Mount
# Named Volume (Dikelola Docker di /var/lib/docker/volumes):
docker run -v nama_volume:/var/lib/mysql mysql

# Bind Mount (Memetakan folder lokal di laptop ke dalam container):
docker run -v $(pwd)/src:/app/src my-dev-app
Kategori 05

Pembersihan Kapasitas Harddisk (Prune)

docker system prune

Membersihkan container mati, image tak terpakai (dangling), dan cache build yang memakan ruang harddisk hingga puluhan gigabytes.

docker system prune -a --volumes  # Hapus container mati + image tak terpakai + volume
