Linux & Bash Terminal Cheatsheet

Panduan praktis perintah CLI (Command Line Interface) sistem operasi Linux. Mulai dari manajemen berkas, kalkulasi hak akses izin numerik, pemfilteran log server bertenaga grep & awk, hingga penjadwalan otomasi crontab.

Kategori 01

Navigasi & Pengelolaan Berkas

ls -la, cd, pwd & mkdir

Perintah dasar memeriksa lokasi direktori aktif (pwd), melihat daftar isi folder lengkap dengan file tersembunyi berawalan titik (ls -la), dan membuat folder bertingkat sekaligus (mkdir -p).

pwd                  # Cetak direktori kerja saat ini
ls -lah              # List berkas format manusia (KB/MB/GB)
mkdir -p app/src/utils  # Buat struktur folder bersarang
cp, mv & rm (Hapus & Salin)

cp -r menyalin folder secara rekursif, mv memindahkan atau mengganti nama berkas, rm -rf menghapus direktori beserta isinya secara paksa.

cp -r folder_sumber folder_tujuan
mv berkas_lama.txt berkas_baru.txt
rm -rf folder_sampah/  # Hati-hati: tidak bisa di-undo!
Kategori 02

Hak Izin Akses (chmod & chown)

AngkaTipe IzinHurufArti
4Read (Baca)rMembaca isi berkas atau melihat isi direktori.
2Write (Tulis)wMengubah, mengedit, atau menghapus berkas.
1Execute (Jalankan)xMenjalankan berkas sebagai program script / memasuki direktori.
Kombinasi Nilai chmod Populer
chmod 755 script.sh  # Owner: Read+Write+Exec (7), Group: Read+Exec (5), Others: Read+Exec (5)
chmod 644 config.txt  # Owner: Read+Write (6), Group: Read (4), Others: Read (4)
chmod 600 id_rsa      # Private key SSH: Hanya Owner yang boleh baca & tulis!
Kategori 03

Pencarian & Pengolahan Teks (grep, awk, sed)

grep (Global Regular Expression Print)

Mencari baris teks di dalam berkas log server. -r rekursif, -n tampilkan nomor baris, -i case-insensitive.

grep -rni "connection refused" /var/log/nginx/
awk & sed (Pemrosesan Kolom & Stream Edit)

awk mengekstrak kolom ke-n (contoh: '{print $1}' ambil IP address). sed mengganti teks massal via stream editor.

# Ambil kolom ke-1, urutkan, hitung frekuensi kemunculan IP address teratas:
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10

# Ganti kata 'staging' menjadi 'production' di config:
sed -i 's/staging/production/g' config.env
Kategori 04

Monitoring Proses & Sumber Daya

top, ps, kill, df & free
top / htop           # Monitor CPU & RAM realtime interaktif
df -h                # Cek sisa kapasitas penyimpanan harddisk
free -m              # Cek penggunaan memori RAM (Megabytes)
kill -9 <PID>        # Menghentikan paksa proses yang macet
Kategori 05

Jaringan, Port & Download

curl, wget & ss / netstat
curl -I https://api.domain.com   # Periksa HTTP response header
ss -tulpn                       # Periksa port aktif yang sedang listening
wget https://url.com/data.zip   # Unduh berkas langsung dari internet
Kategori 06

Penjadwalan Otomatis (Crontab)

Format 5 kolom penentu jadwal crontab (crontab -e):

* * * * * /path/to/script.sh
┬ ┬ ┬ ┬ ┬
│ │ │ │ │
│ │ │ │ └──── Hari dalam Minggu (0 - 7, 0/7 = Minggu)
│ │ │ └────── Bulan (1 - 12)
│ │ └──────── Tanggal dalam Bulan (1 - 31)
│ └────────── Jam (0 - 23)
└──────────── Menit (0 - 59)
Ekspresi CronArtinya
0 2 * * *Jalankan setiap hari jam 02:00 pagi (waktu backup database).
*/15 * * * *Jalankan setiap 15 menit sekali.
0 8 * * 1Jalankan setiap hari Senin jam 08:00 pagi.
