Markdown & GFM Cheatsheet

Panduan praktis menulis dokumen teknis menggunakan Markdown dan GitHub Flavored Markdown (GFM). Mulai dari format tabel, daftar checklist, kotak alert GitHub [!NOTE], visualisasi diagram Mermaid, hingga notasi matematika KaTeX.

Kategori 02

Tabel & Perataan Teks (Alignment)

Titik dua : pada baris pembatas menentukan perataan kolom: rata kiri :---, rata tengah :---:, atau rata kanan ---:.

| Kolom Kiri (Nama) | Rata Tengah (Status) | Rata Kanan (Harga) |
| :--- | :---: | ---: |
| Laptop Pro | Aktif | Rp 15.000.000 |
| Mouse Wireless | Habis | Rp 250.000 |
Kategori 03

Kotak Peringatan (GitHub Alerts)

5 Tipe Alert Box Resmi GitHub
> [!NOTE]
> Informasi pelengkap atau penjelasan latar belakang.

> [!TIP]
> Tips optimasi atau cara tercepat melakukan sesuatu.

> [!IMPORTANT]
> Instruksi atau persyaratan penting yang wajib diikuti.

> [!WARNING]
> Peringatan potensi kesalahan atau perubahan yang merusak.

> [!CAUTION]
> Tindakan berisiko tinggi yang dapat menyebabkan kehilangan data.

Kategori 05

Notasi Matematika KaTeX (LaTeX)

Gunakan tanda dollar tunggal $rumus$ untuk inline math, atau dollar ganda $$rumus$$ untuk formula blok terpusat.

Persamaan Einstein: $E = mc^2$

Rumus Kuadratik:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
