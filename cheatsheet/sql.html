SQL Cheatsheet & Panduan Tes Kerja

Panduan praktis sintaks SQL (Structured Query Language) lengkap untuk manipulasi data relasional. Mulai dari query dasar, agregasi multi-tabel, teknik Window Functions mutakhir, hingga latihan soal simulasi tes teknis rekrutmen.

Kategori 01

Basic Query: Mengambil & Memfilter Data

Fondasi penulisan query SQL standar untuk menarik data dari tabel dengan kriteria spesifik.

SELECT, FROM & WHERE

Mengambil kolom tertentu dari suatu tabel yang memenuhi kriteria kondisi filter logika.

SELECT kolom1, kolom2 FROM nama_tabel WHERE kondisi;
SELECT nama, gaji FROM karyawan WHERE divisi = 'IT' AND status = 'Aktif'; Filter Staf IT Aktif
ORDER BY & LIMIT / TOP

Mengurutkan baris hasil query (ASC untuk urut naik, DESC untuk urut turun) dan membatasi jumlah baris output (contoh: Top 5 gaji tertinggi).

SELECT * FROM tabel ORDER BY kolom DESC LIMIT n;
Catatan Dialek SQL: Di PostgreSQL/MySQL gunakan LIMIT 5 di akhir query. Di Microsoft SQL Server gunakan SELECT TOP 5 ... di awal.
Operator IN, BETWEEN & LIKE

IN mencocokkan nilai dengan daftar list. BETWEEN memeriksa rentang inklusif. LIKE pencocokan pola teks wildcard (% untuk sembarang karakter, _ untuk satu karakter).

WHERE kota IN ('Jakarta', 'Bandung') AND nama LIKE 'A%'
Kategori 02

Agregasi & Perbedaan WHERE vs HAVING

Fungsi ringkasan data dan aturan mutlak penggunaan HAVING saat memfilter hasil agregasi.

GROUP BY & HAVING

Mengelompokkan baris berdasarkan kategori. HAVING memfilter kelompok *setelah* diagregasi, sedangkan WHERE memfilter baris individual *sebelum* dikelompokkan.

SELECT kategori, SUM(total) FROM penjualan GROUP BY kategori HAVING SUM(total) > 100000000;
Jebakan Tes Kerja #1: Jangan pernah meletakkan fungsi agregasi (seperti WHERE COUNT(*) > 5) di dalam klausa WHERE! Itu akan menghasilkan syntax error. Gunakan HAVING COUNT(*) > 5.
Kategori 03

Relasi Antar Tabel (JOINs)

Menghubungkan data dari dua atau lebih tabel berdasarkan kolom kunci relasi (Primary Key & Foreign Key).

Tipe JOIN Perilaku Pencocokan Data Sintaks Contoh
INNER JOIN Hanya menampilkan baris yang memiliki kecocokan di kedua tabel. SELECT * FROM pesanan p INNER JOIN pelanggan c ON p.pelanggan_id = c.id;
LEFT JOIN Menampilkan semua baris tabel kiri + baris cocok di tabel kanan (isi NULL jika tidak ada pasangan). SELECT * FROM pelanggan c LEFT JOIN pesanan p ON c.id = p.pelanggan_id;
RIGHT JOIN Menampilkan semua baris tabel kanan + baris cocok di tabel kiri. SELECT * FROM pesanan p RIGHT JOIN karyawan k ON p.sales_id = k.id;
FULL OUTER JOIN Menampilkan semua data dari kedua tabel, baik yang memiliki kecocokan maupun tidak. SELECT * FROM cabang a FULL OUTER JOIN target b ON a.id = b.cabang_id;
Kategori 04

Subquery & CTE (Common Table Expressions)

Menulis query bersarang dan tabel sementara modular menggunakan klausa modern WITH.

CTE: WITH Clause

Membuat tabel virtual sementara yang membuat query kompleks jauh lebih bersih dan mudah dibaca dibanding subquery bertumpuk.

WITH cte_name AS (SELECT ...) SELECT * FROM cte_name WHERE ...;
Kategori 05

Window Functions (OVER, PARTITION BY, RANK)

Kalkulasi baris per baris tanpa mengubah jumlah baris tabel. Sangat sering ditanyakan pada tes kerja Data Analyst tingkat menengah ke atas.

ROW_NUMBER(), RANK() & DENSE_RANK()

Memberi peringkat data di dalam masing-masing kelompok (PARTITION BY). ROW_NUMBER() nomor unik urut, RANK() melompati nomor jika ada nilai kembar, DENSE_RANK() tidak melompati nomor urut.

DENSE_RANK() OVER (PARTITION BY divisi ORDER BY gaji DESC)
Kategori 06

DDL & DML (Membuat Tabel & Manipulasi Data)

Perintah CRUD dasar: INSERT, UPDATE, DELETE, CREATE TABLE, ALTER TABLE.

INSERT, UPDATE & DELETE

Perintah manipulasi data. PERINGATAN: Selalu gunakan klausa WHERE pada UPDATE dan DELETE agar tidak mengubah/menghapus seluruh isi tabel secara tidak sengaja!

UPDATE tabel SET kolom = nilai WHERE id = 10;  |  DELETE FROM tabel WHERE id = 10;
