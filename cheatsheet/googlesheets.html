Google Sheets & Apps Script Cheatsheet

Panduan rumus mutakhir yang menjadi keunggulan utama Google Sheets dibandingkan Excel tradisional. Menguasai sintaks SQL di spreadsheet lewat QUERY(), penarikan data lintas dokumen IMPORTRANGE(), rumus sebar ARRAYFORMULA(), hingga dasar otomasi Apps Script.

Kategori 01

=QUERY(): Menulis Sintaks SQL di Spreadsheet

=QUERY(data, "query_string", [headers])

Fungsi paling dahsyat di Google Sheets. Menggabungkan fungsi Filter, Sort, SUMIF, dan Pivot Table hanya dalam satu baris teks SQL menggunakan nama huruf kolom (A, B, C) atau Col1, Col2.

=QUERY(A2:E50, "SELECT A, B, D WHERE D > 5000000 ORDER BY D DESC LIMIT 10", 0)
Catatan Penting: Di dalam query string Google Sheets, teks string wajib dibungkus kutip tunggal: WHERE B = 'Jakarta'. Jika data berasal dari kurung kurawal array atau IMPORTRANGE, gunakan penamaan Col1, Col2, Col3 bukan huruf kolom.
Kategori 02

=IMPORTRANGE(): Tarik Data Lintas File Spreadsheet

=IMPORTRANGE("spreadsheet_url", "Sheet!Range")

Menghubungkan dan menarik rentang sel secara langsung dari file Google Spreadsheet lain di cloud secara live. Pertama kali diinput akan muncul tombol "Allow Access".

=IMPORTRANGE("URL_ATAU_ID_SPREADSHEET", "MasterKaryawan!A2:E50")
Kategori 03

=ARRAYFORMULA(): Satu Rumus untuk Seluruh Kolom

=ARRAYFORMULA(rumus_rentang)

Menerapkan perhitungan otomatis ke ribuan baris di bawahnya tanpa perlu meng-copy atau men-drag rumus ke bawah! Tekan Ctrl + Shift + Enter untuk membungkus rumus biasa menjadi ARRAYFORMULA.

=ARRAYFORMULA(IF(A2:A="", "", B2:B * C2:C))
Kategori 04

FILTER, UNIQUE & SORT Dinamis

=FILTER(), =UNIQUE() & =SORT()
=FILTER(A2:C50, B2:B50 = "Laptop", C2:C50 > 1000000)  # Tumpahkan baris yang cocok
=UNIQUE(A2:A100)                                      # Ekstrak daftar unik tanpa ganda
=SORT(UNIQUE(A2:A100), 1, TRUE)                       # Buat daftar unik terurut A-Z
Kategori 05

=SPARKLINE(): Grafik Mini di Dalam Satu Sel

=SPARKLINE(data, [options])
# Grafik garis tren bulanan:
=SPARKLINE(B2:M2, {"charttype", "line"; "color", "green"; "linewidth", 2})

# Grafik batang mini (bar chart):
=SPARKLINE(B2, {"charttype", "bar"; "max", 100; "color1", "blue"})
Kategori 06

Otomasi Google Apps Script (JavaScript)

Buka menu Extensions > Apps Script. Contoh script otomatisasi mengirim email saat ada baris baru:

function kirimEmailOtomatis() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const email = sheet.getRange("A2").getValue();
  const pesan = sheet.getRange("B2").getValue();
  GmailApp.sendEmail(email, "Notifikasi Laporan", pesan);
}
