Hierarki Variabel Postman

Memahami prioritas scope variabel: Local > Data > Environment > Collection > Global.

Sintaks Akses Variabel di URL & Script Configuration

Gunakan double curly braces {{variable_name}} pada antarmuka GUI, dan objek pm.* pada script JavaScript.

// Di URL atau Header: https://api.example.com/v1/users/{{userId}} // Di Pre-request / Tests Script: pm.environment.set("token", "jwt_abc123"); const currentToken = pm.environment.get("token"); pm.collectionVariables.set("baseUrl", "https://api.staging.com");

Assertions & pm.test() Esensial

Snippet pengujian otomatis standar industri menggunakan pustaka Chai Assertion bawaan Postman.

Uji Status HTTP & Properti JSON Response Assertions
// 1. Validasi Status Code pm.test("Status code adalah 200 OK", function () { pm.response.to.have.status(200); }); // 2. Validasi Response Time (Waktu respons di bawah 500ms) pm.test("Response time di bawah 500ms", function () { pm.expect(pm.response.responseTime).to.be.below(500); }); // 3. Validasi Konten JSON Body pm.test("Respons mengembalikan status success dan user id", function () { const json = pm.response.json(); pm.expect(json.success).to.be.true; pm.expect(json.data.user).to.have.property("email"); pm.expect(json.data.user.role).to.eql("admin"); });

Request Chaining (Ekstrak Token Login)

Menyimpan token JWT dari respons endpoint login untuk otomatis dipakai oleh endpoint berikutnya.

Auto-inject Bearer Token Antar Request Automation
// Tulis ini di tab 'Tests' pada request POST /auth/login: if (pm.response.code === 200) { const response = pm.response.json(); // Simpan token ke environment pm.environment.set("accessToken", response.data.token); console.log("Token tersimpan otomatis!"); } // Kemudian di request berikutnya, buka tab 'Authorization', // pilih 'Bearer Token' dan masukkan: {{accessToken}}

Validasi Kontrak JSON Schema

Mencegah bug integrasi dengan memverifikasi tipe data struktur respons backend.

Validasi Schema dengan TinyValidator (tv4) Contract Testing
const schema = { type: "object", required: ["id", "username", "isActive"], properties: { id: { type: "number" }, username: { type: "string" }, isActive: { type: "boolean" } } }; pm.test("Struktur JSON sesuai dengan kontrak schema", function () { pm.expect(tv4.validate(pm.response.json(), schema)).to.be.true; });

Newman CLI untuk CI/CD Pipeline

Menjalankan pengujian Postman secara headless di GitHub Actions, GitLab CI, atau terminal server.

Perintah Eksekusi Newman CLI
# 1. Install Newman & HTML Reporter npm install -g newman newman-reporter-htmlextra # 2. Jalankan Collection dengan Environment tertentu newman run ecommerce-tests.json -e staging-env.json # 3. Buat laporan pengujian interaktif HTML cantik newman run tests.json -e env.json -r cli,htmlextra --reporter-htmlextra-export ./report.html

Quick Reference Objek pm.*

Ringkasan cepat metode objek pm yang paling sering dipakai.

Metode Contoh Sintaks Kegunaan
pm.response.json() const body = pm.response.json(); Parse payload respons menjadi objek JS
pm.environment.set() pm.environment.set("k", "v"); Simpan variabel ke level Environment aktif
pm.response.to.be.success pm.response.to.be.success; Verifikasi status code 2xx (200-299)
pm.variables.get() pm.variables.get("baseUrl"); Mencari variabel di scope terdekat secara hierarkis
postman.setNextRequest() postman.setNextRequest("Delete User"); Mengontrol alur loncatan eksekusi collection runner
