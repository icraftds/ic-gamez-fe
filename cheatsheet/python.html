Python for Data Analysis Cheatsheet

Panduan manipulasi data berkinerja tinggi menggunakan pustaka Pandas & NumPy. Meliputi pembersihan nilai NaN, indexing presisi loc vs iloc, agregasi multi-dimensi groupby, hingga penggabungan dataset relasional.

Kategori 01

Membaca & Menyimpan Data

pd.read_csv & pd.read_excel
import pandas as pd
import numpy as np

df = pd.read_csv('transaksi.csv')
df_excel = pd.read_excel('laporan.xlsx', sheet_name='Sheet1')
df.to_csv('output.csv', index=False)  # Simpan tanpa kolom indeks
Kategori 02

Seleksi Presisi: loc vs iloc

df.loc[] (Label) vs df.iloc[] (Posisi Integer)

loc memilih berdasarkan Nama Label kolom/indeks. iloc memilih murni berdasarkan Nomor Urut Posisi Angka (0-indexed).

# Ambil baris ke-0 s/d 4, dan kolom bernama 'nama' dan 'gaji':
df.loc[0:4, ['nama', 'gaji']]

# Ambil 5 baris pertama, dan 3 kolom pertama berdasarkan posisi angka:
df.iloc[0:5, 0:3]
Kategori 03

Filtering & Querying Data

Boolean Indexing & .query()

Menggunakan operator logika bitwise: & (AND), | (OR), ~ (NOT). Wajib membungkus setiap kondisi dengan tanda kurung!

# Cara 1: Boolean Indexing
df[(df['kota'].isin(['Jakarta', 'Surabaya'])) & (df['omzet'] > 5000000)]

# Cara 2: .query() yang lebih ringkas dan mudah dibaca
df.query('divisi == "Finance" and gaji >= 7000000')
Kategori 04

Pembersihan Data (Missing Values)

isna, fillna & dropna
df.isna().sum()                        # Cek total nilai kosong per kolom
df.dropna(subset=['id_karyawan'])      # Hapus baris yang ID-nya kosong
df['bonus'] = df['bonus'].fillna(0)     # Ganti NaN menjadi 0
df.drop_duplicates(subset=['email'])   # Hapus data duplikat
Kategori 05

GroupBy & Pivot Table

.groupby() & .pivot_table()
# Agregasi beberapa fungsi statistik sekaligus:
df.groupby('divisi')['gaji'].agg(['mean', 'sum', 'count']).reset_index()

# Pivot Table persis seperti di Excel:
df.pivot_table(index='kategori', columns='wilayah', values='omzet', aggfunc='sum', fill_value=0)
Kategori 06

Penggabungan (Merge & Concat)

pd.merge() & pd.concat()

pd.merge() setara dengan SQL JOIN (opsi how='left', 'inner', 'outer'). pd.concat() menumpuk baris secara vertikal atau berdampingan horizontal.

# Menggabungkan dua DataFrame berdasarkan kunci relasi:
df_gabung = pd.merge(transaksi, pelanggan, on='pelanggan_id', how='left')
