HTTP Status & REST API Cheatsheet

Panduan komprehensif protokol HTTP dan arsitektur REST API. Meliputi perbedaan mutlak PUT vs PATCH, matriks pemecahan masalah HTTP Status Codes (perbedaan 401 Unauthorized vs 403 Forbidden, 502 Bad Gateway), tata kelola header CORS, serta standar penamaan endpoint URL profesional.

Kategori 01

HTTP Methods (Verbs) & Idempotency

MetodeTujuan / AksiIdempotent?Safe?Body Payload?
GETMengambil data resource tanpa mengubah data server.YaYa (Safe)Tidak dianjurkan
POSTMembuat resource baru di server.TIDAKTidakYa (Wajib)
PUTMengganti seluruh data resource secara utuh (Replace all).YaTidakYa (Full entity)
PATCHMengubah sebagian kecil kolom resource (Partial update).TergantungTidakYa (Partial)
DELETEMenghapus resource tertentu.YaTidakOpsional
Arti Idempotent: Sebuah metode disebut Idempotent jika dipanggil 1 kali atau 100 kali berturut-turut dengan data yang sama akan menghasilkan kondisi akhir sistem yang sama persis (contoh: DELETE ID 5). Sebaliknya, POST tidak idempotent karena 2 kali POST akan membuat 2 baris data baru!
Kategori 02

Matriks HTTP Status Codes Paling Sering Muncul

KodeNama StatusKapan Terjadi?Contoh Skenario
200OKPermintaan HTTP sukses dieksekusi.GET data profil berhasil dimuat.
201CreatedResource baru sukses dibuat di server.POST pendaftaran user baru sukses.
204No ContentAksi sukses, tidak ada isi body yang dikembalikan.DELETE berhasil dieksekusi.
301Moved PermanentlyURL resource telah pindah alamat secara permanen.Migrasi domain lama ke domain baru.
304Not ModifiedKonten belum berubah, browser pakai cache lokal.Cache browser menghemat kuota internet.
400Bad RequestSintaks request salah, payload JSON cacat format.JSON lupa kurung tutup kurawal.
401UnauthorizedBelum Login / Token Hilang atau Expired.Akses data privat tanpa Header Authorization Bearer.
403ForbiddenSudah Login, tapi Tidak Punya Izin Akses (Hak Role).Akun Staff biasa mencoba membuka endpoint Admin.
404Not FoundURL endpoint atau resource ID tidak ditemukan di server.Mencari user dengan ID 9999999.
422Unprocessable EntityFormat JSON benar, tapi validasi kolom bisnis gagal.Email salah format atau password kurang dari 8 karakter.
429Too Many RequestsPengguna melampaui batas kuota request (Rate Limiting).User melakukan 100 kali klik tombol per detik.
500Internal Server ErrorKode backend crash, exception unhandled di server.Error null pointer exception di backend.
502Bad GatewayReverse Proxy (Nginx) gagal menghubungi aplikasi backend.Container Node.js mati di belakang Nginx.
504Gateway TimeoutServer backend terlalu lama merespons hingga timeout.Query database berat memakan waktu lebih dari 60 detik.
