Auto Layout Mastery

Fitur fundamental Figma yang mengadopsi konsep CSS Flexbox untuk membuat tata letak responsif dinamis.

Resizing Behaviors: Fixed, Hug & Fill Layout

Tiga mode dimensi lebar dan tinggi elemen di dalam frame Auto Layout.

Hug Contents: Frame otomatis menyusut atau melebar mengikuti total ukuran konten anak di dalamnya (contoh: tombol pill yang menyesuaikan panjang teks).
Fill Container: Elemen meregang memenuhi sisa ruang yang tersedia di frame induknya (mirip flex: 1 di CSS).
Fixed Width / Height: Ukuran dimensi statis dalam pixel terlepas dari konten di dalamnya.
Wrap (Baru): Elemen anak otomatis turun ke baris baru ketika lebar frame induk tidak lagi mencukupi (mirip flex-wrap: wrap).
Shortcut Cepat: Tekan Shift + A untuk membungkus layer ke dalam frame Auto Layout, atau Option + Shift + A (Mac) / Alt + Shift + A (Win) untuk menghapusnya.

Komponen, Variasi & Component Properties

Arsitektur komponen modular untuk menjaga konsistensi UI di ratusan layar desain.

4 Tipe Component Properties Architecture

Mekanisme efisien mengurangi jumlah varian kombinasi yang meledak (variant explosion).

1. Variant: Untuk perubahan visual mayor (misal: Size = Small | Medium | Large, Hierarchy = Primary | Secondary | Ghost).
2. Boolean Property: Toggle on/off untuk elemen opsional (misal: hasIconLeft = true/false atau showBadge).
3. Text Property: Memungkinkan perubahan teks langsung dari panel kanan tanpa harus mengklik dua kali layer teks di canvas.
4. Instance Swap: Memungkinkan mengganti ikon atau sub-komponen dengan cepat dari katalog ikon yang kompatibel.

Sistem 8pt Grid & Design Tokens

Standar industri untuk ritme visual, jarak, dan skalabilitas antar platform.

Aturan 8-Point Grid System Spacing

Seluruh margin, padding, tinggi tombol, dan jarak antar elemen menggunakan kelipatan 8px (atau sub-grid 4px untuk elemen mikro).

Nilai Spacing Standar: 4px (xxs) -> Jarak micro, border-radius kecil, badge padding 8px (xs) -> Gap antar icon dan label teks 16px (sm) -> Default inner padding tombol dan kartu 24px (md) -> Gap antar section atau form fields 32px (lg) -> Spacing antar grup modul besar 48px (xl) -> Spacing section container desktop 64px (xxl) -> Hero section vertical padding
Mengapa 8px? Sebagian besar resolusi layar digital (termasuk rasio Retina 2x dan 3x) dapat dibagi bulat dengan angka 8 tanpa menghasilkan rendering pecahan pixel (anti-aliasing blur).

10 Prinsip Heuristik UX Jakob Nielsen

Fondasi evaluasi usability yang selalu diujikan dalam wawancara Product Design.

10 Heuristik Usability Jakob Nielsen Evaluation
1. Visibility of System Status: Sistem selalu memberi umpan balik yang tepat waktu (contoh: loading spinner, upload progress bar).
2. Match System & Real World: Gunakan istilah, metafora, dan bahasa yang akrab bagi pengguna (ikon keranjang belanja, folder).
3. User Control & Freedom: Sediakan pintu darurat yang jelas saat salah klik (tombol Undo, Cancel, Redo).
4. Consistency & Standards: Pertahankan terminologi dan konvensi platform (ikon magnifying glass selalu berarti Search).
5. Error Prevention: Desain terbaik mencegah terjadinya error sejak awal (validasi real-time form, konfirmasi hapus data penting).
6. Recognition over Recall: Minimalkan beban ingatan pengguna dengan membuat opsi dan tindakan terlihat langsung di layar.
7. Flexibility & Efficiency: Sediakan jalan pintas (accelerator/shortcut) bagi pengguna mahir tanpa membingungkan pemula.
8. Aesthetic & Minimalist: Hapus elemen visual yang tidak relevan agar tidak mengaburkan informasi krusial (tingkatkan signal-to-noise ratio).
9. Help Users Recognize Errors: Pesan kesalahan ditulis dalam bahasa manusia sederhana, jelaskan apa masalahnya dan tawarkan solusi perbaikan.
10. Help & Documentation: Sediakan panduan dan dokumentasi pencarian yang mudah diakses saat pengguna buntu.
