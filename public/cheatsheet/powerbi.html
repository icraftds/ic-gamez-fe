Power BI & DAX Cheatsheet

Panduan komprehensif bahasa ekspresi analisis data DAX (Data Analysis Expressions) dan arsitektur pemodelan data Star Schema. Menguasai fungsi sakti CALCULATE(), kalkulasi tren Year-Over-Year, serta pemahaman row context vs filter context.

Kategori 01

Calculated Column vs Measure: Perbedaan Mutlak

AspekCalculated ColumnMeasure
Waktu KalkulasiDihitung saat data dimuat (Refresh / Data load).Dihitung dinamis saat runtime (ketika user mengklik slicer visual).
Penyimpanan MemoriDisimpan ke dalam memori RAM (menambah ukuran file .pbix).Tidak disimpan di disk/RAM, dihitung instan oleh mesin VertiPaq.
ContextMemiliki Row Context (evaluasi baris per baris).Memiliki Filter Context (evaluasi berdasarkan filter visual).
Kapan Digunakan?Hanya jika kolom dibutuhkan sebagai slicer atau tajuk baris/kolom matriks.Untuk semua nilai agregasi numerik (Total Omzet, % Margin, YoY).
Kategori 02

CALCULATE(): Fungsi Paling Penting di DAX

CALCULATE(Expression, [Filter1], ...)

Satu-satunya fungsi di DAX yang mampu memodifikasi, menimpa, atau menghapus Filter Context yang sedang aktif pada visual dashboard.

Total_Sales_Jakarta = CALCULATE(
  [Total_Sales],
  Dim_Customer[City] = "Jakarta"
)
ALL() & Menghitung Persentase Total

Fungsi ALL() menghapus seluruh filter pada tabel/kolom yang ditentukan untuk mendapatkan Grand Total yang statis sebagai pembagi persentase.

%_Contribution =
DIVIDE(
  [Total_Sales],
  CALCULATE([Total_Sales], ALL(Dim_Product)),
  0
)
Kategori 03

Time Intelligence (YTD, MTD & YoY)

DATESYTD & SAMEPERIODLASTYEAR
# Total Penjualan Kumulatif Tahun Berjalan (YTD):
Sales_YTD = CALCULATE([Total_Sales], DATESYTD(Dim_Date[Date]))

# Penjualan Periode Sama Tahun Lalu (SPLY / YoY):
Sales_Last_Year = CALCULATE([Total_Sales], SAMEPERIODLASTYEAR(Dim_Date[Date]))
Kategori 04

Iterator Functions (SUMX, RELATED)

SUMX(Table, Expression)

Fungsi berakhiran "X" berjalan baris demi baris (Row Context) lalu menjumlahkan hasilnya. RELATED() menarik nilai dari tabel dimensi lain yang terhubung relasi.

Total_Revenue =
SUMX(
  Fact_Sales,
  Fact_Sales[Quantity] * RELATED(Dim_Product[UnitPrice])
)

KomponenCiri & KarakteristikContoh Tabel
Fact Table (Tabel Fakta)Tabel transaksi di tengah, berisi angka metrik (omzet, qty, diskon) dan Foreign Key ID. Memiliki jutaan baris.Fact_Sales, Fact_Orders
