JavaScript ES6+ Cheatsheet

Panduan praktis sintaks modern JavaScript. Menguasai metode array fungsional mutakhir (map, filter, reduce), pemrograman asynchronous (async/await, Promise.all), trik destrukturisasi, manipulasi DOM, hingga konsep closure yang sering diujikan pada wawancara teknis.

Kategori 01

Array Methods Modern (Immutability)

.map(), .filter() & .reduce()

Trio metode fungsional paling penting. Mengembalikan array baru tanpa memodifikasi data array asli (non-mutating).

// .map() : Transformasi setiap elemen menjadi nilai baru
const hargaPajak = harga.map(h => h * 1.11);

// .filter() : Saring elemen yang memenuhi kondisi TRUE
const produkAktif = produk.filter(p => p.stok > 0);

// .reduce() : Akumulasi array menjadi satu nilai tunggal
const totalOmzet = transaksi.reduce((total, t) => total + t.nominal, 0);
.find(), .some() & .every()
// .find() : Mengembalikan 1 elemen pertama yang cocok (atau undefined)
const user = users.find(u => u.email === 'budi@mail.com');

// .some() : Mengembalikan true jika minimal SALAH SATU elemen cocok
const adaYangGagal = tes.some(t => t.skor < 60);

// .every() : Mengembalikan true jika SEMUA elemen cocok
const semuaLulus = tes.every(t => t.skor >= 75);
Kategori 02

Destructuring & Rest/Spread (...)

Object & Array Destructuring
// Ekstrak properti object dengan nilai default:
const { nama, email, role = 'Member' } = user;

// Spread operator untuk clone object tanpa mutasi:
const userBaru = { ...user, status: 'Aktif' };

// Gabung dua array secara instan:
const semuaItem = [...makanan, ...minuman];
Kategori 03

Asynchronous: Promises & async/await

async / await dengan try...catch
async function ambilData() {
  try {
    const res = await fetch('https://api.example.com/data');
    const data = await res.json();
    return data;
  } catch (error) {
    console.error('Terjadi error:', error);
  }
}
Promise.all() untuk Fetch Paralel

Menjalankan beberapa request HTTP sekaligus secara paralel dan menunggu semuanya selesai bersamaan.

const [user, post] = await Promise.all([
  fetchUser(userId),
  fetchPosts(userId)
]);
Kategori 04

DOM Manipulation & Event Delegation

querySelector & addEventListener
// Seleksi elemen dan ubah teks/class:
const tombol = document.querySelector('.btn-submit');
tombol.classList.toggle('active');

// Event Delegation: Cukup pasang 1 listener di parent!
document.querySelector('#daftar').addEventListener('click', (e) => {
  if (e.target.matches('.item-hapus')) {
    e.target.closest('tr').remove();
  }
});
Kategori 05

LocalStorage & SessionStorage

localStorage dengan JSON
// Simpan object (wajib JSON.stringify):
localStorage.setItem('profile', JSON.stringify({ nama: 'Budi', level: 5 }));

// Baca object (wajib JSON.parse):
const profile = JSON.parse(localStorage.getItem('profile')) || {};

// Hapus item:
localStorage.removeItem('profile');
