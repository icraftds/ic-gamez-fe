# 🚀 Cheatsheet Portal & Career Technical Test Guide

Portal panduan belajar, cheatsheet modern, dan bank latihan soal interaktif berpenjelasan lengkap untuk persiapan tes rekrutmen kerja dan referensi harian. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript murni** (tanpa framework dan tanpa backend).

---

## 🌟 Fitur Utama

- **24 Modul Cheatsheet Lengkap:** Mulai dari Excel, SQL, TypeScript, Kubernetes, Web Security, UI/UX Figma, hingga HR & Payroll.
- **300+ Soal Latihan Interaktif:** Dilengkapi pembahasan mendalam, pengacakan soal, dan kalkulasi skor otomatis di setiap halaman.
- **Live Search & Quick Filter:** Cari rumus, fungsi, atau perintah secara instan (Shortcut: `Ctrl+K` / `Cmd+K`).
- **Dark Mode & Light Mode:** Sinkronisasi tema otomatis antar seluruh 24 halaman via `localStorage`.
- **Copy to Clipboard:** Salin rumus atau perintah sekali klik dengan notifikasi toast.
- **Print & PDF Ready:** Didesain khusus agar rapi saat dicetak atau disimpan sebagai PDF (`Ctrl+P`).
- **Tanpa Backend / Build Step:** Cukup clone dan buka `index.html` langsung di browser Anda.

## 🚀 Cara Menjalankan

Tidak memerlukan instalasi Node.js, Python, atau web server lokal.

1. Clone repositori:
   ```bash
   git clone https://github.com/irsyaad06/cheatsheet.git
   ```
2. Buka berkas `index.html` dengan peramban favorit Anda (Google Chrome, Microsoft Edge, Safari, Firefox).
