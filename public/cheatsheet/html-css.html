HTML5 & Modern CSS Cheatsheet

Panduan praktis perancangan layout web modern. Menguasai struktur semantik HTML5 yang ramah SEO dan aksesibilitas, rahasia penataan elemen 1 dimensi (Flexbox) vs 2 dimensi (CSS Grid), pemahaman tuntas box-sizing: border-box, dan tipografi cairan responsif dengan clamp().

Kategori 01

Tag Semantik HTML5 (SEO & A11y)

Tag HTML5Fungsi SemantikMengapa Penting?
<header>Pengantar halaman atau seksi, memuat logo dan navigasi utama.Membantu screen reader mengenali tajuk situs.
<nav>Blok yang berisi tautan navigasi utama.Memungkinkan mesin pencari memahami struktur situs.
<main>Konten inti dominan (hanya boleh ada 1 per halaman).Pintasan "Skip to Content" untuk aksesibilitas.
<article>Konten mandiri yang dapat didistribusikan terpisah (post blog, produk).Standar sindikasi RSS feed dan Google News.
<section>Pengelompokan tematik konten yang memiliki judul spesifik.Membagi bab konten secara terstruktur.
<aside>Konten pelengkap sampingan (sidebar, iklan, artikel terkait).Memisahkan konteks pelengkap dari alur utama.
<footer>Catatan kaki situs (hak cipta, legalitas, kontak).Penanda akhir dokumen web.
Kategori 02

CSS Box Model: box-sizing: border-box

Reset Box-Sizing Universal Wajib

Secara default, CSS menggunakan content-box di mana padding dan border akan menambah lebar fisik elemen sehingga tata letak sering jebol/rusak. Menggunakan border-box membuat padding dan border dihitung ke dalam lebar yang sudah ditentukan.

*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
Kategori 03

Flexbox (Layout 1 Dimensi)

Trik Menaruh Elemen Persis di Tengah Layar (Centering)
.container {
  display: flex;
  justify-content: center; /* Sumbu Utama Horizontal */
  align-items: center;     /* Sumbu Silang Vertikal */
  min-height: 100vh;
}
Properti FlexboxPilihan NilaiPengaruh Visual
justify-contentflex-start, center, flex-end, space-between, space-aroundMengatur distribusi ruang di sepanjang Sumbu Utama (Main Axis).
align-itemsstretch, center, flex-start, flex-end, baselineMengatur posisi elemen di sepanjang Sumbu Silang (Cross Axis).
flex-directionrow, row-reverse, column, column-reverseMenentukan arah aliran item (mendatar atau menurun).
gap1rem, 20px, 2vwMemberikan jarak renggang otomatis antar elemen tanpa margin kotor.
Kategori 04

CSS Grid (Layout 2 Dimensi Modern)

Grid Responsif Otomatis Tanpa Media Queries!

Rumus sakti CSS Grid modern yang otomatis menyesuaikan jumlah kolom di desktop (3-4 kolom), tablet (2 kolom), dan mobile (1 kolom) tanpa menulis satupun @media breakpoint!

.cards-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}
Kategori 05

Tipografi Cairan & CSS Variables

clamp(min, preferred, max)

Mengubah ukuran teks atau padding secara halus dan proporsional sesuai lebar layar perangkat.

/* Font judul: minimal 1.5rem di HP, membesar dinamis, maksimal 3rem di Desktop */
h1 { font-size: clamp(1.5rem, 4vw + 1rem, 3rem); }
